# Asymptotic Complexity Analysis

| Algorithm Module | Best Case Time | Average Case Time | Worst Case Time | Space Complexity |
|---|---|---|---|---|
| **EMI Calculator** | $O(1)$ | $O(1)$ | $O(1)$ | $O(1)$ |
| **Greedy Salary Allocation** | $O(1)$ | $O(1)$ | $O(1)$ | $O(1)$ |
| **DP Goal Knapsack** | $O(N \cdot B)$ | $O(N \cdot B)$ | $O(N \cdot B)$ | $O(N \cdot B)$ |
| **Divide & Conquer Merge Sort** | $O(N \log N)$ | $O(N \log N)$ | $O(N \log N)$ | $O(N)$ |
| **QuickSort Expenses** | $O(N \log N)$ | $O(N \log N)$ | $O(N^2)$ | $O(\log N)$ |
| **Binary Search by Amount** | $O(1)$ | $O(\log N)$ | $O(\log N)$ | $O(1)$ |
| **Linear Search / Filter** | $O(1)$ | $O(N)$ | $O(N)$ | $O(N)$ |
| **Backtracking Search** | $O(1)$ | $O(2^N)$ (Pruned) | $O(2^N)$ | $O(N)$ |
| **Branch & Bound Deficit** | $O(1)$ | $O(N \log N)$ | $O(2^N)$ | $O(2^N)$ |

Where:
- $N$ is the number of financial items/records.
- $B$ is the discrete budget capacity units.
